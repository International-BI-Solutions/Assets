# International BI Solutions — Logo Usage Guidelines

## Concept
The symbol is a **data cube** (the OLAP cube at the heart of business intelligence). Each face says something different:
- **Top, 2×2 grid:** the dashboard.
- **Left, solid face:** foundation and trust.
- **Right, rising bars:** growth.

The gaps between the faces are part of the logo and must never be filled in.

## Versions
| File | Use |
|---|---|
| `ibs-horizontal.svg` | Primary version: web, documents, email signatures |
| `ibs-stacked.svg` | Square or vertical spaces: covers, signage, social media |
| `ibs-symbol.svg` | Symbol only, when the name already appears nearby |
| `ibs-symbol-small.svg` | Simplified version for sizes below 48 px |
| `*-reversed.svg` | On dark backgrounds (indigo or black) |
| `*-black.svg`, `*-white.svg`, `*-mono-1e1b4b.svg` | One colour: stamps, engraving, embroidery |
| `ibs-app-icon.svg`, `ibs-favicon.svg` | App icon and browser tab |

## Colours
| Colour | HEX | RGB | CMYK (approx.) | Use |
|---|---|---|---|---|
| Deep indigo | `#1E1B4B` | 30 27 75 | 60 64 0 71 | Primary colour: text and backgrounds |
| Data cyan | `#22D3EE` | 34 211 238 | 86 11 0 7 | Dashboard tiles; accents |
| Violet | `#6366F1` | 99 102 241 | 59 58 0 5 | Bars on light backgrounds |
| Light violet | `#818CF8` | 129 140 248 | 48 44 0 3 | Bars on dark backgrounds |

Pantone equivalents are approximate (cyan ≈ 311 C, indigo ≈ 2765 C, violet ≈ 2726 C). Confirm them against a physical swatch book before printing.

## Clear space
Keep a minimum clear space around the logo equal to **the height of one dashboard tile** in the symbol (≈ 1/6 of the cube's height). No text, borders or other elements may enter this area.

## Minimum sizes
- **Horizontal logo:** 120 px wide on screen, 30 mm in print. Below that, use the symbol on its own.
- **Symbol:** 24 px. Between 16 and 48 px, use `ibs-symbol-small`, which has wider gaps.

## Backgrounds
- **White or light backgrounds:** full-colour version.
- **Indigo, black or dark photos:** `reversed` version, with the left face in white.
- **Coloured backgrounds or busy photos:** one-colour white or black version.

## Don't
- Change the face colours or swap them around.
- Fill in the gaps or add outlines or shadows.
- Stretch, rotate or skew the logo.
- Change the typeface or the proportion between the symbol and the text.
- Place the full-colour version on an indigo background (the left face disappears).

## Typography
The logo text is set in **Bahnschrift** (Semibold and Light), already converted to outlines, so the files look the same without the font installed. For brand text (web, documents), use Bahnschrift or, as an open-licence alternative, **Barlow** or **Inter**.

> Note: Bahnschrift is a Microsoft font that ships with Windows. Before registering the trademark, confirm that its licence allows use in a logo, or rebuild the text with an open-licence font such as Barlow.

## Before registering
Run a professional trademark search (your country's trademark office and a reverse image search) to make sure no existing logo is too similar.
